Jobs

LocalBotz is a small open-source project. There are no open roles right now — but the work is open, and so is the code.

No open roles right now

We are not hiring at the moment. When that changes, the roles will be listed here — with real titles, real descriptions, and a real way to apply. Until then, the honest answer is: nothing open.

Work with us the open way

The best way to work with LocalBotz today is to contribute on GitHub — code, docs, bot templates, translations, or a guide that needs a clearer limit.

1

Use it

Download LocalBotz and use it for real work. The best contributions start there.

2

Find a gap

An open issue, a missing template, a language that needs work — pick something real.

3

Build it

From scratch, in LocalBotz's own code. Ideas from other projects are welcome; copied code and names are not.

4

Send it

Open a pull request on GitHub. We review in the open, and say plainly what needs to change.
