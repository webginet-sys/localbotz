Workflows that act when a deal moves

A rule is: when a deal moves to a stage, then a chain of steps, in order. Up to 10 steps: create a task, run an office job, write a draft, add a note, wait, or check a condition first.

Example

Quoted — chase after 3 days

Wait 3 days. If the deal is still Quoted, write a chase draft and add a note. If it moved on, the chain stops and writes nothing.

Example

Won — start the handover

When a deal is won, a handover draft is written on the deal — or an office job starts, with the Auditor and the approval gate, like any office job.

Example

Lost — ask why

When a deal is lost, a note asks for the reason. The reason stays on the timeline, where the next quotation can learn from it.

Always-on monitors

Two watchers ship with the app: a deal Quoted for 3 days with no reply gets a chase draft and a task; a deal stuck in Negotiation for 7 days gets a nudge. Each fires once per deal — never a nag loop. Add your own, or pause them.

Nothing is sent by a workflow

✓

Drafts stay drafts. A workflow writes a draft on the deal. You send it yourself — by email, WhatsApp, or in person.

✓

Office jobs go through approval. A workflow that starts an office job still waits for the Auditor and for you.

✓

Every run is on the record. The Runs page shows what every chain did, step by step — and a finished run can be re-run.

✓

Values stay numbers. A deal worth 4,850,000 is written as 4,850,000 — never as 4.85e+06.
